# accordion — раскрывающиеся полосы

Заголовок раздела и несколько свёрнутых полос: видно всё оглавление, читается выбранное. Внутрь
полосы кладут любые блоки каталога — абзац, список, совет, ссылку.

## Откуда взялся вид

**Решение владельца 2026-09-19, дословно:** «Дело эту идею достаточно компактно при необходимости
можешь использовать раскрывающуюся карточку типа аккордеон чтобы показать больше описание».

Задача, ради которой вид заведён: корневая страница слоя архитектора обязана объяснить десяток тем
сразу. Простыню текста не читают, а сокращение до трёх строк теряет половину сказанного. Аккордеон —
третий ответ.

## Когда брать и когда НЕ брать

| Берут | Не берут |
|---|---|
| тем много, читать будут одну-две | тем две-три и обе короткие — обычные абзацы честнее |
| у каждой темы своя начинка (список, совет, ссылка) | это вопросы и ответы — тогда `faq` |
| текст важен, но не всем и не сразу | текст обязателен к прочтению — свёрнутое не читают вовсе |

🔒 **Это НЕ `faq`, и различие не в оформлении.** У «вопросов и ответов» своя семантика: `<dl>` — пара
«термин — определение», постоянный якорь `faq-heading`, один раздел на страницу и своё место в
разметке для поисковика. Там разметка и есть содержание; взять её ради похожего вида значит соврать.

## Устройство

```
{ kind: 'accordion', title?: string, lead?: string, capped?: boolean, cards?: boolean, children: Block[] }
{ kind: 'accordionItem', summary: string, open?: boolean, children: Block[] }
```

🔒 **`cards: true` — каждая полоса отдельной карточкой с отступом** (279, слово владельца 2026-09-23:
«одно решение одна карточка аккордеон за доступно открытие только одной карточки»). Для списка
самостоятельных сущностей — решений, товаров; без поля — прежний вид, одна рамка с разделителями.
Открытой по-прежнему бывает одна полоса.

🔒 **Ячейка — контейнер, а не строка.** Довод оплачен у `cards`: внутрь кладут не только абзац.
Строка такого не выражает, и вид пришлось бы расширять полями «а ещё список».

🔒 **`open` ставится не более чем одной полосе.** Раскрытые по умолчанию полосы перестают быть
аккордеоном: человек получает ту же простыню, ради сворачивания которой вид и заведён. Рендерер берёт
первую помеченную и остальные помечает свёрнутыми.

🔒 **Открыта одна полоса за раз** (`type="single" collapsible`). Закрыть последнюю оставшуюся человек
имеет право — иначе экран навсегда занят разделом, который он дочитал.

## Что легко сделать неправильно

🛑 **Положить внутрь `accordion` что-то кроме `accordionItem`.** Такой блок негде открыть, и он
исчезнет с экрана без следа. Тип этого не даёт, а рендерер молча отбрасывает чужих детей — последняя
линия для материала, собранного не типами.

🛑 **Спрятать сюда то, что человек обязан прочесть.** Свёрнутое не читают; предупреждение о том, что
сайт открыт без авторизации, живёт в аккордеоне только потому, что его ПЕРВАЯ строка видна всегда.

🔒 **Вид состоит из двух половин, и это не сложность ради сложности.** Раскрытие живёт движением, а ни
один файл под `sections/` не бывает клиентским. Поэтому рендерер серверный и только переводит блоки в
пропсы островка `components/accordion/accordion-section.client.tsx` — тот же приём, что у `workspace`
и у диаграмм. Содержимое приходит островку **уже нарисованным**: он не знает о видах и не заводит
второй системы разметки.
