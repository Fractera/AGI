# NEXUS-A2A

**Открытый исследовательский проект: децентрализованная сеть, в которой ИИ-агенты разных владельцев находят друг друга, работают
друг на друга и рассчитываются без посредника.**

[English version](README.md) · Начат 2026-10-09 (тег `nexus-a2a-genesis`)

---

## Зачем этот проект

Fractera разрабатывает NEXUS-A2A **как научно-исследовательский проект**. Он не преследует явных коммерческих целей, связанных с
архитектурой Web3. Его цель — привлечь внимание сообщества к созданию инфраструктуры, которую мы считаем перспективной: сети, где
ИИ-агент на компьютере обычного человека — полноправный участник глобальной экономики агентов. Его можно найти, до него можно
достучаться, ему платят за работу, и посередине не стоит ни одна компания.

## Что мы строим

Одно ядро, две роли. **[Fractera/AGI](https://github.com/Fractera/AGI) — ядро узла.** То же ядро может взять и роль
**супер-узла**: тогда оно ставит программу супер-узла из её собственного репозитория **Fractera/nexus-supernode** и запускает её
рядом с собой.

```
            ┌──────────────────────────────── глобальная сеть ─────────────────────────────┐
            │                                                                             │
            │   СУПЕР-УЗЛЫ — Fractera/nexus-supernode, с залогом:                          │
            │   поиск, мосты через NAT, расчёты                                            │
            │   (ставит ядро Fractera в роли супер-узла — или отдельно, само по себе)      │
            │                                                                             │
            └──────────▲──────────────────────▲──────────────────────────▲──────────────┘
                       │                      │                          │
                 ┌─────┴─────┐          ┌─────┴─────┐              ┌─────┴─────────────┐
                 │   УЗЕЛ    │          │   УЗЕЛ    │              │ любой проект A2A  │
                 │ Fractera/ │◄── A2A ─►│ Fractera/ │              │ (не Fractera)     │
                 │ AGI ядро  │          │ AGI ядро  │              │ агенты Google A2A │
                 └───────────┘          └───────────┘              └───────────────────┘
```

| | Узел | Супер-узел |
|---|---|---|
| Репозиторий | `Fractera/AGI` — ядро | `Fractera/nexus-supernode` — отдельный репозиторий |
| Где работает | компьютер человека или флешка | сервер с постоянным публичным адресом |
| Часть Web3 | кошелёк, клиент эскроу, клиент поиска — внутри ядра | таблица поиска, мосты, бандлер, залог |
| Как появляется | человек ставит Fractera | его ставит ядро Fractera в роли супер-узла — тем же способом, каким ядро ставит элементы; или любой ставит его отдельно |

Работа над Web3 принадлежит **ядру**, а не элементам: элементы несут только **коннекторы A2A**.

### Узел — собственное пространство агентов человека

**Узел** — пространство, где человек запускает своих агентов. В идеальной форме это **флешка**: любой может сделать её или купить,
вставить в свой компьютер и получить локальное пространство со своим агентом внутри. С агентом человек говорит по **HTTP** или через
мессенджер, например **Telegram**.

Из этого разговора узел обрастает новыми возможностями. Каждая возможность — **элемент**: отдельный микросервис со своим маршрутом
на **поддомене** или на **собственном домене** человека, открытый публично или доступный только тем, кому после регистрации выдан
привилегированный доступ. Шаблоны, которые создаёт Fractera, — удобные **стартеры** именно для этого: из одного стартера получается
сайт, магазин, память, панель — то, что человек попросит агента построить.

Внутри узла элементы и их агенты вызывают друг друга по протоколу **A2A** (Google, A2A v1.0): каждый элемент публикует визитку
агента, и соседи вызывают его напрямую.

### Супер-узел — автономный публичный слой

**Супер-узел** — автономная часть архитектуры: программа **Fractera/nexus-supernode** на сервере с постоянным публичным адресом, чей
оператор вносит **залог**. Ядро Fractera, переключённое в роль супер-узла, ставит её из репозитория; её можно поставить и отдельно,
без Fractera. Супер-узлы делают то, чего домашний компьютер в одиночку не может:

- **поиск** — держат распределённую таблицу (Kademlia DHT), где агенты публикуют, как до них достучаться;
- **достижимость** — помогают двум агентам за домашними роутерами соединиться напрямую (пробивка NAT), а если не вышло —
  пересылают их зашифрованный трафик, не имея возможности его прочитать;
- **расчёты** — несут платёжную инфраструктуру: упаковывают операции агентов для блокчейна и обслуживают эскроу, которое защищает
  обе стороны сделки.

Поэтому супер-узел — отдельный репозиторий: он **не привязан к Fractera**. Он обслуживает любой проект, чьи агенты говорят на
протоколе **A2A** от Google — стандарте на момент старта, — и на других протоколах агентов, когда те появятся.

### Роль узлов и супер-узлов в монете

У сети есть свой служебный токен **$NEXUS**. Его не майнят: фиксированный объём создаётся один раз при запуске. Его ценность
привязана к тому, сколько полезной работы агенты делают друг для друга:

1. **Агент узла** берёт заказ у другого агента. Оплата заказчика (в USDC) блокируется в эскроу-контракте и уходит агенту по
   подписанной квитанции.
2. Малая **комиссия протокола** с каждой закрытой сделки покупает $NEXUS на открытом рынке и **сжигает** его. Чем больше агенты
   работают, тем больше $NEXUS уходит из обращения.
3. **Супер-узлы** получают плату за пересылку трафика и обработку операций и держат $NEXUS в залоге, который теряют за саботаж или
   простой. Честная работа оплачивается, обман стоит залога.
4. **Репутация** агента строится только из оплаченных закрытых сделок, поэтому боты, торгующие друг с другом, накрутить её не
   могут.

Коротко: **узлы создают спрос** (агенты делают оплачиваемую работу), **супер-узлы дают инфраструктуру** (и получают за неё плату),
а **токен их связывает** — его становится меньше по мере того, как сеть делает больше настоящей работы.

## Принципы

- **Нет единой точки отказа.** Если Fractera завтра исчезнет, ничто из запущенного человеком не перестанет работать.
- **Всё принадлежит человеку:** узел, агенты, домен, ключи.
- **Сначала открытые стандарты:** Google A2A для вызовов между агентами; наши дополнения — расширения A2A, а не новый формат.
- **Инфраструктура не может прочитать содержимое:** трафик между агентами зашифрован от агента до агента.
